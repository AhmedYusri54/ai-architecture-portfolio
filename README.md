## How to read this repo

| Folder | What's in it |
|---|---|
| [`docs/`](docs/) | One file per session (`01-framing.md`, `02-building-blocks.md`, ...). Read them in order to follow how the design evolved. |
| [`diagrams/`](diagrams/) | Exported diagrams (PNG/SVG) plus their editable source files in `diagrams/src/`. |
| [`adr/`](adr/) | Architecture Decision Records, one per decision (`0001-model-hosting.md`, ...). Each records the context, the options, and why one was chosen. |
| [`capstone/`](capstone/) | The final architecture document (PDF) and slides. |

**Short on time?** Start with the capstone, then skim the ADRs to see the key trade-offs.
